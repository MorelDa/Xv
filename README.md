# Invitación XV Años — GitHub Pages

Paquete estático listo para GitHub Pages.

## Publicación
1. Sube TODO el contenido de esta carpeta al repositorio.
2. `index.html` debe quedar en la raíz.
3. `assets/` debe quedar en la raíz junto a `index.html`.
4. `.nojekyll` debe permanecer en la raíz.
5. En Settings → Pages selecciona Deploy from a branch → `main` → `/ (root)`.

## Personalización
La fecha y nombre están en la sección `CONFIGURACIÓN` dentro de `index.html`.
